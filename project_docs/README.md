# Obsidian AI Assistant Documentation

This directory contains comprehensive documentation for the Obsidian AI Assistant project, a serverless application that helps users manage and interact with their Obsidian notes through AI-powered features.

- [Architecture](overview/architecture.md) - System architecture and design decisions

### Tasks

- [Task Board](tasks/task_board.md) - Current tasks and their status

### CI/CD

## Quick Start

1. For a high-level overview of the project, start with [System Summary](overview/system_summary.md)
2. To understand the technical architecture, read [Architecture](overview/architecture.md)
3. For development setup, see [Docker Setup](containers/docker_setup.md)
4. To contribute, review the [CI/CD](cicd/pipeline.md) and [Testing](cicd/testing.md) documentation

## Contributing

When contributing to the project:
1. Review the [Task Board](tasks/task_board.md) for current priorities
2. Follow the [Linting & Formatting](cicd/linting_formatting.md) guidelines
3. Ensure all tests pass as described in [Testing](cicd/testing.md)
4. Document any new decisions in the [Decisions Log](tasks/decisions_log.md)

## Maintenance

This documentation is maintained by the development team. When making significant changes:
1. Update relevant documentation files
2. Update diagrams if needed
3. Review and update the [Decisions Log](tasks/decisions_log.md)
4. Ensure all links are working correctly
